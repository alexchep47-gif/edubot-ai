# EduBot AI

Tutoriel 3D interactif (Node.js + Three.js). Français par défaut, bouton EN/FR, chat démo.

## Lancer

```bash
node server.js
```

Ouvre http://localhost:3000

Aucune dépendance npm requise. Three.js est chargé depuis un CDN.

## Contrôles

- Glisser : orbiter
- Molette : zoomer
- Clic sur un cristal ou un module : changer d'étape
- Lancer le tutoriel : ouvre le chat

## Structure

```
server.js
public/index.html
public/css/style.css
public/js/main.js
```
